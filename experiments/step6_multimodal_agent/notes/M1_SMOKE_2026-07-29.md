# M1 smoke — 2026-07-29

The first M1 slice is implemented: a deterministic multimodal cue-and-recall
Gymnasium environment, separate image/byte/symbolic/phase encoders, a shared
latent projection, and an actor-critic training loop.

CPU smoke command:

```bash
PYTHONPATH=src:. .venv/bin/python experiments/step6_multimodal_agent/scripts/run_m1_smoke.py --episodes 100 --seed 0
```

Observed results with 200 episodes and seed 0:

| Model | Mean reward, last 20 episodes |
|---|---:|
| memoryless baseline | 0.35 |
| recurrent GRU control | 0.85 |

The recurrent control exceeds the memoryless baseline on the hidden-cue task.
This is only a sanity signal, not evidence for a Loop Transformer advantage:
the GRU is the control that the shared recurrent Transformer must beat at
matched parameter/FLOP budgets.
